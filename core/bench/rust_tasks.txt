=== fizzbuzz
--- prompt
Escribe en Rust `fn fizzbuzz(n: u32) -> Vec<String>` que devuelva los valores de 1 a n: "Fizz" para múltiplos de 3, "Buzz" para múltiplos de 5, "FizzBuzz" para múltiplos de ambos y el número como texto en otro caso.
--- tests
#[test] fn basic() { let v = fizzbuzz(15); assert_eq!(v.len(), 15); assert_eq!(v[0], "1"); assert_eq!(v[2], "Fizz"); assert_eq!(v[4], "Buzz"); assert_eq!(v[14], "FizzBuzz"); assert_eq!(v[6], "7"); }
#[test] fn zero() { assert!(fizzbuzz(0).is_empty()); }

=== palindrome
--- prompt
Escribe en Rust `fn is_palindrome(s: &str) -> bool` que ignore mayúsculas/minúsculas y todo carácter que no sea alfanumérico. Debe funcionar con texto Unicode (acentos, ñ): compara caracteres, no bytes.
--- tests
#[test] fn yes() { assert!(is_palindrome("Anita lava la tina")); assert!(is_palindrome("A man, a plan, a canal: Panama")); assert!(is_palindrome("")); assert!(is_palindrome("ñoñ")); assert!(is_palindrome("Ésé")); }

=== rpn
--- prompt
Escribe en Rust `fn eval_rpn(expr: &str) -> Result<i64, String>` que evalúe una expresión en notación polaca inversa: enteros (pueden ser negativos, como "-3") y operadores `+ - * /` separados por espacios. === matmul
--- prompt

--- tests

=== config
--- prompt
En Rust, con este tipo de error:
```rust
#[derive(Debug, PartialEq)]
pub enum ConfigError { MissingEquals { line: usize }, EmptyKey { line: usize }, DuplicateKey { key: String, line: usize } }
```
escribe `fn parse_config(input: &str) -> Result<std::collections::HashMap<String, String>, ConfigError>` que lea líneas `clave = valor` (recortando espacios en clave y valor), ignore líneas vacías y las que empiezan por `#`, y devuelva el error correspondiente con el número de línea (empezando en 1). Incluye la definición de `ConfigError`.
--- tests
#[test] fn ok() { let m = parse_config("# c\nname = Ana\n\n edad=30 \nurl = a=b").unwrap(); assert_eq!(m.len(), 3); assert_eq!(m["name"], "Ana"); assert_eq!(m["edad"], "30"); assert_eq!(m["url"], "a=b"); }

=== group_by
--- prompt
Escribe en Rust la función genérica `fn group_by<T, K, F>(items: Vec<T>, key: F) -> std::collections::BTreeMap<K, Vec<T>> where K: Ord, F: Fn(&T) -> K` que agrupe los elementos por la clave que devuelve `key`, conservando el orden original dentro de cada grupo.
--- tests
#[test] fn parity() { let g = group_by(vec![1, 2, 3, 4, 5], |x| x % 2); assert_eq!(g[&0], vec![2, 4]); assert_eq!(g[&1], vec![1, 3, 5]); assert_eq!(g.len(), 2); }
#[test] fn strings() { let g = group_by(vec!["ana", "bo", "al", "bea"], |s| s.chars().next().unwrap()); assert_eq!(g[&'a'], vec!["ana", "al"]); assert_eq!(g[&'b'], vec!["bo", "bea"]); }
#[test] fn empty() { let g = group_by(Vec::<i32>::new(), |x| *x); assert!(g.is_empty()); }
